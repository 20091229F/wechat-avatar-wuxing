# 评分标准与分析深度模块

本文件定义微信头像分析的标准评分维度、分析深度等级和产出物规范。这些标准来自大量实战案例（13+ 案例）的沉淀。

## 一、综合评分体系（5 维度 × 5 分制）

| 维度 | 满分 | 评分要点 |
|---|---|---|
| 太极点清晰度 | 5/5 | 人物是否居中、单人、正面、清晰突出；无人物主体（纯风景/卡通/徽章）计 0 分 |
| 四象限五行平衡 | 5/5 | 上火/下土/左木/右金/中央土各方位是否得位、有无相克或过旺 |
| 用神补益度 | 5/5 | 头像主色调是否补命主喜用神；补用神得高分，忌神旺则扣分 |
| 情感与人物特质 | 5/5 | 是否传递命主性别气质（女性温柔贤惠/男性稳重进取）、亲和力、正缘桃花磁场 |
| 健康暗示 | 5/5 | 有无五行过旺克伐疾患之象、画面冷暖是否与命局寒燥相悖 |

**总分换算**：X/25 → (X/25×10) 保留一位小数。

**评分等级**：
- 9.0–10.0 优秀：建议长期使用
- 7.5–8.9 良好：建议使用，可微调
- 6.0–7.4 中等：建议调整后再用
- 4.0–5.9 较差：建议更换
- 0–3.9 不合格：应立即更换

**历史案例基准分**（用于校准，案例已匿名）：
- 案例A｜日落湖景（无人物、水火交战）：2.4/10
- 案例B｜金色山水徽章（无人物、金水旺）：1.6/10
- 案例C｜新年插画（用神水旺但节日主题）：7.6/10
- 案例D｜手绘卡通人形（木火双补）：8.8/10
- 案例E｜暖橙红花卉版（火土双补+桃花）：9.4/10

## 二、分析深度等级

### Level 1 — 快速点评（即时对话）
适用：用户说"分析下""这个头像怎么样""先不形成word"。
产出：直接在对话中输出完整分析（八字→拆解→四象限→健康→财位→评分→调整建议），不生成文件。

### Level 2 — 多方案对比选优
适用：用户提供 2–5 张候选头像求最佳。
产出：逐一打分对比表 + 排名 + 推荐结论及理由 + 精益求精微调建议。

### Level 3 — 专业版报告（Word）
适用：用户说"形成分析报告""备份成word""写入报告"。
产出：专业版 .docx，包含：
1. 封面（标题+案例名+日期）
2. 一、八字排盘与命格分析（四柱、日主、纳音、旺衰、用神喜忌）
3. 二、头像五行拆解（元素五行归属表）+ 头像图片
4. 三、四象限分析表（方位/四象/本位五行/头像呈现/吉凶）
5. 四、健康分析（引用克伐疾患速查 + 五脏开窍）
6. 五、财位分析（年命/日命/时命/八宅四维财位表）
7. 六、综合评分表（5维度）
8. 七、调整方案（至少 2–3 套，每套含思路+具体做法）
9. 八、养生建议（饮食/作息运动/情志）
10. 九、结语

### Level 4 — 客户版报告（Word 或 PDF）
适用：用户说"给客户的报告""客户版""温馨版"。
产出：温馨简明风格，少专业术语、突出情感共鸣：
1. 封面（专属定制感+头像图+日期）
2. 关于您（以五行比喻命主特质，如"乙木花草之木""戊土城墙之土"）
3. 当前头像解读（生活化语言说优点与问题）
4. 调整方案卡片（2–3 套，卡片式排版）
5. 宜用色/忌用色分卡
6. 健康小贴士
7. 温馨祝福（"亲爱的XX"开头，情感共鸣收尾，落款祝福语）

### Level 5 — 复评/更新版
适用：客户更换头像后再次分析。
产出：在原报告基础上增加新旧对比表（各维度旧分→新分）、提升幅度、微调建议；文件名加"-复评版"或"-更新版"。

## 三、客户信息收集模板

分析前必须收集（缺失时先询问再分析；仅缺时辰可先按日主+月令分析并声明局限）：

| 信息 | 用途 | 缺失处理 |
|---|---|---|
| 姓名（或案例编号） | 报告称呼与文件名 | 用"案例N"编号 |
| 性别 | 阴阳定位、气质传递分析 | 必须询问 |
| 出生日期（公历/农历注明） | 排八字 | 必须询问 |
| 出生时间（注明是否夏令时） | 定时柱、定旺衰 | 缺失时声明分析局限 |
| 求测侧重点（求财/桃花/事业/健康） | 调整方案侧重 | 默认综合分析 |

## 四、文件输出规范

- 输出目录：`~/Desktop/微信头像调整/`
- 专业版命名：`{姓名}-微信头像评估报告.docx`
- 客户版命名：`{姓名}-客户版报告.docx`
- 复评版命名：`{姓名}-微信头像评估报告-复评版.docx` / `{姓名}-客户版报告-复评版.docx`
- 更新版命名：`{姓名}-微信头像评估报告-更新版.docx`
- PDF 客户版命名：`{姓名}-客户版报告-新头像分析.pdf`
- 生成脚本保存在工作区根目录：`generate_{拼音或英文名}_doc.py`（Word）/ `generate_{name}_pdf.py`（PDF）

## 五、工具链要求

- Word 生成：python-docx（使用当前环境的 `python3` 运行）
- PDF 生成：reportlab + UnicodeCIDFont('STSong-Light')（无需 libreoffice）
- 图片嵌入：PIL 读取原始尺寸按比例缩放
- 排八字：使用 WebSearch 查询"YYYY年M月D日 日柱 干支"确认四柱（不要凭记忆硬算）

## 六、分析方法补充规则（实战沉淀）

1. **纳音+日干双法并用**：先报日主（子平正宗），再补纳音年命，两者互参。
2. **身旺身弱判断口诀**：得令（月令生扶）、得地（地支有根）、得势（天干透助）——三得一为旺，两失一为弱；具体案例需 WebSearch 排盘后综合判断。
3. **无人物头像直接扣 0 分**：太极点缺失是最大败笔，无论画面多美。
4. **流动之物皆属水**：人流、河流、车流、波浪纹，不论颜色皆属水（取象优先于颜色）。
5. **节日主题头像提示短期使用**：如"马到成功"等过年元素，建议正月十五后更换。
6. **头像换新复评**：必须做新旧对比表，量化提升幅度，这是客户感知价值的关键。
7. **女性客户重点看正缘桃花**：端庄得体（有领有袖）、温柔亲和、暖色调=旺正缘；吊带冷调=招烂桃花。
8. **多人头大忌**：画面中出现多个人脸（含背景照片）——分运、招第三者、是非口舌。
